# 💬 Babilonia777 — Chat en Tiempo Real

Aplicación de chat en tiempo real construida con **Firebase Realtime Database**, **Cloudinary** para multimedia, y **JavaScript puro** (vanilla). Diseñada como PWA ligera para móviles.

---

## 📋 Características

- ✅ **Registro/Login con contraseña hasheada** (SHA-256)
- ✅ **Mensajes de texto en tiempo real** vía Firebase
- ✅ **Mensajes de audio** (MediaRecorder API)
- ✅ **Cámara integrada** con cambio frontal/trasera y flash (si el dispositivo lo soporta)
- ✅ **Galería de imágenes** con caption opcional
- ✅ **Subida a Cloudinary** con barra de progreso
- ✅ **UI oscura** responsive con safe-area para iPhone
- ✅ **Detección de pestaña oculta** para detener grabación/cámara
